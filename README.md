# StockSmart: Live Trade & Insights

** Made by: Darsh Patel**


---

## Abstract


StockSmart is a web application designed to provide users with the latest updates on the stock market, making it easy to stay informed about company news and data comparisons through responsive and user-friendly graphs. Connected to a MongoDB database, StockSmart allows users to store information and conduct mock trading, providing precise profit or loss values. The app automatically updates every 15 seconds to ensure users have the most current information. It also displays peer performance for companies, simplifying the trading process. The application is fully responsive and easy to use. Using the Finnhub API, I have integrated real-time data retrieval via Node.js/Express.js and developed a custom RESTful API for the frontend to deliver fast and efficient results. The MongoDB database supports mock trading by facilitating buy/sell transactions.

---

## Description

- Developed a responsive web application utilizing ReactJS for the frontend and Node.js with Express for the backend, enabling users to search for stocks via the Finnhub API.
- Implemented features including real-time stock value updates, autocomplete functionality, and detailed stock information pages. Utilized HighCharts to display historical stock market data for the past two years and hourly stock price data for the last six hours.
- Designed a watchlist and portfolio management system, stored in MongoDB, to allow users to track favorite stocks and manage their portfolios, enhancing the overall user experience.
- Deployed both the frontend and backend on Amazon Web Services (AWS) for 1 month and then on Google Cloud Platform (GCP) as well, incorporating Bootstrap for responsive design and implementing conditional styling and modal forms for buying and selling stocks with input validation.
- Enhanced and streamlined performance with advanced caching, reducing data fetch times by 40% and ensuring transaction integrity through seamless asynchronous handling with AJAX and jQuery.
